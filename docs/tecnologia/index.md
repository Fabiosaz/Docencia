# Tecnologia · 4t ESO

Projectes tecnològics, electrònica analògica i digital, pneumàtica, control i robòtica, i tecnologia sostenible.

!!! tip "Com funcionen els exercicis"
    Al final de cada apartat trobaràs exercicis per practicar el que acabes de llegir. La solució està amagada: fes clic a **Solució** per desplegar-la. Al final de cada unitat hi ha uns quants **reptes** més oberts, que sovint es poden fer al taller o amb un simulador. Intenta resoldre cada exercici tot sol i obre la solució només per comprovar-la.
