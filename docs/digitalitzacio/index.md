# Digitalització · 4t ESO

La matèria s'organitza en quatre blocs de sabers bàsics:

1. Dispositius digitals, sistemes operatius i de comunicació.
2. Digitalització de l'entorn personal d'aprenentatge.
3. Seguretat i benestar digital.
4. Ciutadania digital crítica.

Aquests blocs es desenvolupen en set unitats:
